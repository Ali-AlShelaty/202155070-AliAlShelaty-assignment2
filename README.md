# Personal Portfolio — Assignment 2

## Project Description
This is a responsive personal portfolio website developed from
Assignment 1. It includes an **About Me** section, a **Projects**
showcase, and a **Contact** form.

Assignment 2 adds project filtering, live search, and improved user
feedback to make the website more interactive and useful.

Built with plain **HTML, CSS, and JavaScript** — no frameworks or build
tools required.

## Features
- Responsive layout for desktop, tablet, and mobile using CSS Flexbox and Grid
- Dark / light theme toggle with saved preference (`localStorage`)
- Friendly feedback when theme preferences cannot be saved
- Time-of-day greeting generated with JavaScript
- Project category filtering and live search
- Project result count and “No projects found” feedback
- Smooth scrolling navigation with a mobile hamburger menu
- Contact form with client-side validation and confirmation messages
- Hover transitions and a confirmation animation
- Keyboard accessibility and reduced-motion support

The contact form is a front-end demo. No messages are actually sent.

## Setup Instructions (Run Locally)
1. Download and extract the project, or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

Keep the folder structure unchanged so the CSS and JavaScript load
correctly. No installation is required.
