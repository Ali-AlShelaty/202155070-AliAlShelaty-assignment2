# AI Usage Report

## Tools Used & Use Cases

| Tool | How I Used It |
|------|----------------|
 Claude and ChatGPT 
- Planning the structure of the portfolio website.
- Generating and explaining HTML, CSS, and JavaScript ideas.
- Suggesting responsive-design techniques. 
- Reviewing code structure and identifying possible improvements.
- Helping prepare project documentation. 

## Benefits & Challenges

**Benefits**
AI helped speed up the initial development process and provided explanations when implementing features such as responsive layouts, theme switching, and form interaction.

**Challenges**
One challenge was that AI-generated code can contain unnecessary features or assumptions. The suggestions therefore needed to be reviewed and adjusted to match the assignment requirement.

## Learning Outcomes
- Structuring a semantic HTML page.
- Organizing CSS into logical sections.
- Using CSS Grid and Flexbox for responsive layouts.
- Connecting JavaScript to HTML elements with DOM methods.
- Handling button clicks and form submission events.

## Responsible Use & Modifications
AI was used as an assistance and learning tool rather than as a replacement for understanding the code.

I reviewed the generated suggestions, selected the parts relevant to the assignment, and modified the website structure, content, styling, and JavaScript behavior.

The final project was checked against the assignment requirements and the code was organized into separate HTML, CSS, JavaScript, and documentation files.
